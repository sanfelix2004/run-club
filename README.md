# run club giovinazzo

A production-ready single-page website for **run club giovinazzo** — a friendly running community on the Adriatic coast in Giovinazzo, Puglia.

## Features

- Immersive parallax hero with interactive particle canvas
- Fixed navigation with responsive hamburger mobile menu
- Smooth scroll navigation between sections
- Scroll-triggered fade-in animations
- Card-based session grid
- Animated statistics counter
- Pricing table with highlighted plan
- Testimonial carousel with auto-advance
- Booking form with confirmation state
- Google Maps embed and contact details
- Social media links in minimal footer

## Tech Stack

- [Next.js](https://nextjs.org/) 16 (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) v4
- [shadcn/ui](https://ui.shadcn.com/) components
- [Framer Motion](https://www.framer.com/motion/) for animations

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/           # Next.js app router (layout, page, styles)
├── components/    # Page sections and UI components
└── lib/           # Constants and utilities
```

## Design

- **Colors:** Emerald (#10B981) and Forest (#064E3B) on a light background
- **Style:** Parallax / immersive with scroll-driven depth effects
- **Tone:** Casual and friendly
